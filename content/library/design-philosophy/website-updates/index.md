## Updates Log - ACPI Website 2.0
This page is a log of all significant updates to the second ACPI website (launched in the ACPI Annual Meeting, October 2026, to mark the Golden Jubilee of the ACPI)


### 22 October 2026, 2306hrs
Public launch of enhanced and revamped ACPI website by Bp. Simon Almeida in the inauguration function of ACPI.

***
### 20 October 2026, 2306hrs
Test launch of bare-bones version of revamped ACPI website.
The foundation of the website is a Github repository.The static website is built by Hugo and served by Github pages. Hugo theme applied: Congo.
